# Mohanathas Thujeeban — Personal Portfolio

Award-level, scroll-driven interactive personal portfolio built with React 19, TypeScript, Vite, Lenis smooth scrolling, GSAP ticker, and custom WebP video frame rendering engine with CSS 3D perspectives.

## 🚀 Features

- **Custom Video Stage Engine**: Canvas-based frame-scrubbing sequence with 192 high-precision WebP frames, background matte removal, smooth interpolation, and mouse parallax.
- **Scroll Engine**: Lenis smooth scroll synchronized via GSAP ticker with normalized multi-scene progress tracking.
- **Interactive Scenes**:
  - **Hero**: Immersive entrance with dynamic roles, status indicator, and HUD navigation.
  - **About**: Word-by-word reveal on scroll highlighting engineering background at University of Moratuwa.
  - **Work**: 3D perspective project deck showcasing BloomCare+, Prepaid eSIM Web App, and AI-Driven Cyber Threat Intelligence.
  - **Journey**: Visual timeline detailing professional experience at Neirah Tech and academic achievements.
  - **Skills**: Interactive 3D Fibonacci sphere and continuous skill marquee with level indicators.
  - **Awards & Milestones**: 3D interactive cylinder cards highlighting global & national hackathons (IEEE, MoraXtreme).
  - **Contact**: Smooth split-color transition with direct email wipe action and social links.
- **Responsive & Accessible**: Optimized for mobile, tablet, and desktop with adaptive typography and layouts.

## 🛠 Tech Stack

- **Framework**: React 19, TypeScript, Vite
- **Animation & Motion**: Lenis, GSAP
- **Typography**: Anton, Inter Tight, JetBrains Mono
- **Styling**: Vanilla CSS with custom 3D transforms, glassmorphism, and responsive breakpoints
